
# FlowCheck — Power Automate Troubleshooting Knowledge Base

Welcome to the FlowCheck knowledge base.

FlowCheck is an AI-powered troubleshooting assistant built using Microsoft Copilot Studio to help users diagnose and resolve Microsoft Power Automate cloud-flow failures.

## Diagnostic Knowledge Areas

- KB-01: Authentication and Connection Failures
- KB-02: Permissions and Access Control
- KB-03: Expressions and Data Handling
- KB-04: Throttling, Timeouts and Service Errors
- KB-05: Triggers and Workflow Execution
- KB-06: Safe Troubleshooting and Escalation

## Knowledge Standards

Each troubleshooting reference includes:

- Symptoms and error indicators
- Possible causes
- Required diagnostic evidence
- Recommended verification steps
- Potential resolutions
- Prevention guidance
- Official Microsoft documentation references

## Responsible Troubleshooting

FlowCheck provides advisory guidance only.

It does not directly access, execute, modify or repair cloud flows.

Never share passwords, API keys, access tokens or confidential information when requesting assistance.

## Sources

Technical guidance is informed by official Microsoft Learn documentation.

This is an independent community project, not an official Microsoft support service.
